# Document Review

ドキュメントの作成・更新後に整合性を確認するワークフロー。

## ワークフロー

このチェックリストをコピーして進行状況を追跡する:

```
タスク進捗：
- [ ] ステップ1: 対象ファイルを読み直す
- [ ] ステップ2: 整合性を確認する
- [ ] ステップ3: 関連ファイルを確認・更新する
```

**ステップ1: 対象ファイルを読み直す**

作成または更新したファイル全体を `Read` ツールで読み込む。

**ステップ2: 整合性を確認する**

内容面と形式面の両方を確認する。

内容面:

| 観点 | 確認内容 |
|------|----------|
| 論理性 | 説明が一貫しているか、矛盾がないか |
| 正確性 | 情報が正しいか、コード例が実装と一致しているか |
| 既存との整合 | 他のドキュメントと矛盾していないか |

形式面:

| 観点 | 確認内容 |
|------|----------|
| 構成 | 見出しレベルが適切か、セクション順序が論理的か |
| 文体 | 常体（だ/である）で統一されているか |
| 表記 | 固有名詞・カタカナ表記が規則に従っているか |
| リンク | 内部リンクが正しいパスを指しているか |
| 配置 | ディレクトリ構造に適合しているか |

文体・表記の詳細は [docs/README.md](../../../docs/README.md) を参照。

**ステップ3: 関連ファイルを確認・更新する**

| 関連ファイルの例 | 確認内容 |
|------------------|----------|
| README.md | ファイル一覧への追加、説明文との整合性 |
| 目次・索引 | 新規追加・削除の反映 |
| 参照元ドキュメント | リンク切れ、説明の齟齬 |

問題を発見した場合は修正し、再度ステップ1から確認する。
