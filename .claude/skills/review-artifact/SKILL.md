# Artifact Review

コードまたはドキュメントの作成・更新後に整合性を確認するワークフロー。

## ワークフロー

このチェックリストをコピーして進行状況を追跡する:

```
タスク進捗：
- [ ] ステップ1: 対象ファイルを読み直す
- [ ] ステップ2: 整合性を確認する
- [ ] ステップ3: 関連ファイルを確認・更新する
```

**ステップ1: 対象ファイルを読み直す**

作成または更新したファイル全体を `Read` ツールで読み込む。

**ステップ2: 整合性を確認する**

| 観点 | 新規作成 | 更新 |
|------|----------|------|
| 論理・意味 | プロジェクトの方針と一致しているか | 既存の文脈と矛盾していないか |
| 構成 | 見出しレベル、セクション順序が適切か | 同左 |
| コード例 | 実装と一致しているか | 同左 |
| 配置 | ディレクトリ構造に適合しているか | - |

**ステップ3: 関連ファイルを確認・更新する**

| 関連ファイルの例 | 確認内容 |
|------------------|----------|
| README.md | ファイル一覧への追加、説明文との整合性 |
| 目次・索引 | 新規追加・削除の反映 |
| 参照元ドキュメント | リンク切れ、説明の齟齬 |

問題を発見した場合は修正し、再度ステップ1から確認する。
