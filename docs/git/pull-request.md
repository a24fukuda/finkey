# Pull Request規約

本プロジェクトのPull Requestの運用ルールを定める。

## タイトル

### 形式

```
<type>: <subject>
```

コミットメッセージのタイトルと同じ形式を使用する。Pull Requestに含まれる変更の主たる目的を表す。

### 例

```
feat: トレイメニューにアップデートボタンを追加
fix: オーバーレイのちらつきを修正
docs: CHANGELOGを追加
```

## 本文

### 構成

| セクション | 内容 |
|-----------|------|
| Summary | 変更内容の概要（箇条書き1-3点） |

### テンプレート

```markdown
## Summary
- 変更点1
- 変更点2
```

**記述のポイント:**
- 「何を」「なぜ」を簡潔に
- 箇条書きで1-3点にまとめる

## マージ

### スカッシュマージ

Pull Requestはスカッシュマージを使用する。

**マージコミットのメッセージ形式:**

```
<type>: <subject>

- <type>: <subject>
- <type>: <subject>
- ...
```

| 項目 | 内容 |
|------|------|
| タイトル | Pull Requestのタイトルをそのまま使用 |
| 本文 | 含まれる各コミットの `<type>: <subject>` を箇条書きで列挙 |

### 例

Pull Requestに以下のコミットが含まれる場合：

```
feat: ダークモード切り替えボタンを追加
fix: テーマ切り替え時のちらつきを修正
refactor: カラー定数を共通化
```

マージコミットのメッセージ：

```
feat: ダークモード対応

- feat: ダークモード切り替えボタンを追加
- fix: テーマ切り替え時のちらつきを修正
- refactor: カラー定数を共通化
```
